318 // A = m x n 'this' is factored as A = LQUP, where
319 // L is m x m lower unit triangular
320 // U is m x n upper triangular
321 // Q is a m x m permutation matrix
322 // P is an n x n permutation matrix
323 // However, the result is constructed in an abbreviated, encoded format:
324 // First, the entries of A are modified:
325 // L and U are placed into A
