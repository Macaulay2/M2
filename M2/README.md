This directory is the top level of the Macaulay2 source tree.

See the [Wiki](https://github.com/Macaulay2/M2/wiki) for current installation
instructions, build guides, and contributor information. The "Building M2 from
source" section of the wiki is the current entry point for the autotools and
CMake build workflows.

To use Ninja by default, set `export CMAKE_GENERATOR=Ninja` in your shell.
See [BUILD/README.md](BUILD/README.md) for details.
