# `prism/`, `pygments/`, `vim/`, `emacs/` — per-editor grammar packages

The four subdirectories hold the **per-editor grammar packages**
generated by [`make-M2-symbols.m2`](file-make-M2-symbols.md).
Each is a complete, self-contained package ready to ship to that
editor's plugin ecosystem.

Part of [`editors/`](README.md).

[← editors/ overview](README.md) · [← top-level engine TOC](../../../README.md)

## `prism/` — PrismJS syntax highlighter

```
prism/
├── README.md
├── index.js
├── macaulay2.js.in       (template)
├── macaulay2.js          (generated)
├── package.json
├── prism-M2.css
└── webpack.config.js
```

PrismJS is the JavaScript syntax highlighter used on the public
[macaulay2.com](https://macaulay2.com) website.

- **`macaulay2.js.in`** → template with `@SYMBOLS@` placeholder.
- **`macaulay2.js`** → generated, distributed via npm as
  `prism-macaulay2`.
- **`prism-M2.css`** → matching colour theme.
- **`webpack.config.js`** → bundling config when shipped to npm.
- **`package.json`** → npm metadata.

The webpack/npm machinery exists because PrismJS plugins
distribute through npm; this subdir is essentially a small npm
package living inside M2's repo.

## `pygments/` — Pygments syntax highlighter

```
pygments/
├── README.md
└── macaulay2.py.in       (template)
```

Pygments is the Python syntax highlighter used by Sphinx and
many other documentation systems. M2 ships a
`macaulay2.py.in` template; building generates `macaulay2.py`.

To install:

```sh
cp macaulay2.py /path/to/pygments/lexers/
```

or use Pygments' plugin entry point.

## `vim/` — Vim syntax + plugin

```
vim/
├── README.md
├── README_linux
├── README_macos
├── VimM2.scpt
├── m2.vim.dict
├── m2.vim.dict.in
├── m2.vim.plugin
├── m2.vim.syntax
```

A complete Vim package:

- **`m2.vim.syntax`** — `:syntax` definitions (highlighting
  rules). Generated from `.in`.
- **`m2.vim.dict`** — word list for `:dictionary`-based
  completion.
- **`m2.vim.plugin`** — auxiliary plugin code (key bindings,
  filetype detection).
- **`VimM2.scpt`** — macOS AppleScript wrapper for "open in M2".

Multiple READMEs cover platform-specific install steps
(Linux vs macOS).

## `emacs/` — symbolic link to M2-emacs submodule

```
emacs/
└── README.md
```

In the source tree, `emacs/` is mostly a placeholder: the real
content lives in the [M2-emacs](https://github.com/Macaulay2/M2-emacs)
GitHub repository, vendored as a **git submodule** (see
[`M2/submodules/`](../../submodules/README.md)).

The submodule contains:

- `M2-symbols.el` (generated).
- `M2.el` (the actual `M2-mode` major mode).
- `M2-init.el`, `M2-comint.el`, `M2-help.el`, ... full editor
  integration.

Splitting it into its own repo lets it follow MELPA / package.el
release cadence independently of M2's source tree.

## How the four interact with `make-M2-symbols.m2`

```
make-M2-symbols.m2 runs:
    generateGrammar("prism/macaulay2.js", ...)
       → reads prism/macaulay2.js.in
       → substitutes @SYMBOLS@
       → writes prism/macaulay2.js
    generateGrammar("pygments/macaulay2.py", ...)
       → ... same pattern ...
    generateGrammar("vim/m2.vim.syntax", ...)
       → ... same pattern ...
    generateGrammar("emacs/M2-symbols.el", ...)
       → writes into submodule path
```

## Used by

- End users of each editor.
- The M2 website (loads `prism/macaulay2.js`).
- Sphinx docs (loads `pygments/macaulay2.py`).
