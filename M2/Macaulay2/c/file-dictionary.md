# `dictionary.c`, `dictionary.h` — symbol-table / scope management

`dictionary.c` and `dictionary.h` implement the **symbol table and
scoping** used by `scc1` during parsing and semantic analysis.
Tracks definitions, exports, imports between `.d` files.

Part of the [`c/` scc1 translator](README.md).

[← back to c/ overview](README.md) · [← top-level engine TOC](../../../README.md)

## What's exported

```c
extern char *uniquify(char *);
extern char *totoken(char *);
extern void exportit(node, scope);
extern char *prefixify(node, char *);
extern void checkfordeferredsymbols();
extern void reinternsymbol(node, scope);
```

`uniquify` produces unique mangled names; `exportit` marks a
symbol as exported (visible to other `.d` modules); `prefixify`
applies a module prefix.

## Internal structure

```c
#include "scc.h"
#define extern
#include "dictionary.h"
#undef extern

static node hash_buckets[7313];
```

The classic header-include-with-extern-redefined trick to declare
storage *exactly once* (the others get `extern` declarations only).

The `hash_buckets[7313]` array is a fixed-size hash table —
7313 is a prime chosen for distribution. Each bucket is a
linked chain of `node`s (using [`list.c`](file-list.md)).

## Scopes

Scopes form a **linked list of dictionaries**:

```
global_scope
   ├── module_scope (for current .d file)
   │    ├── function_scope (for current function)
   │    │    ├── block_scope (for current block)
   │    │    │    └── ...
```

Each `scope` carries its own local symbol entries plus a pointer
to its parent. Lookup walks up the chain.

## Export / import

A `.d` file uses `export foo := ...` to make `foo` visible to
other files via `use modulename;`. `scc1`'s job:

1. When parsing `export foo`: call `exportit(foo, current_scope)`.
2. When parsing `use modulename`: read modulename's `.sig` file and
   `reinternsymbol` each exported entry into the current scope.

The `.sig` file is the on-disk representation of a module's
exports — generated by [`cprint.c`](file-cprint.md) as part of
output emission.

## Deferred symbols

```c
extern void checkfordeferredsymbols();
```

Some references can't be resolved at first sight (forward
references within the same file, mutually recursive definitions).
`scc1` records them as "deferred" and resolves them at
`checkfordeferredsymbols()` time before code emission.
