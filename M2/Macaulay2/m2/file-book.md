# `book.m2` — package-to-LaTeX-book rendering

`book.m2` defines the **book-style LaTeX rendering** of an M2
package's documentation. It takes a package whose docs have been
generated by [`file-installPackage.md`](file-installPackage.md) and
produces a single coherent LaTeX document suitable for book / chapter
formatting.

Part of the [`m2/` Core layer](README.md).

## How `book` differs from `installPackage`

`installPackage` produces a **collection** of per-node HTML / LaTeX
files. `book` produces a **single** large LaTeX document that
imposes book-style typography (chapters, sections, table of
contents, index).

The use case: producing print-ready documentation for the *Macaulay2
Book* or for any package author who wants a single LaTeX file.

## Output structure

A `book Package` produces:

- Title page using the package's metadata.
- Table of contents.
- One chapter per doc-node group.
- Bibliography from CITE references.
- Index using doc-node tags.

The output goes through `pdflatex` like any LaTeX document.

## Used by

- The Macaulay2 book itself.
- Package authors producing printed documentation.
- `book Package` invoked by users.
