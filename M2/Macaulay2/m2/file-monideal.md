# `monideal.m2` — `MonomialIdeal` type

`monideal.m2` defines the M2-side **`MonomialIdeal`** type — a
specialised `Ideal` subclass for ideals generated by monomials.
Operations on a `MonomialIdeal` use the engine's much-faster
monomial-ideal path ([`../e/file-monideal.md`](../e/file-monideal.md))
rather than the general polynomial-ideal path.

Part of the [`m2/` Core layer](README.md).

[← back to m2 overview](README.md) · [← top-level engine TOC](../../../README.md)

## What's declared

```m2
needs "hilbert.m2"     -- for poincare
needs "matrix2.m2"

MonomialIdeal = new Type of Ideal
```

`MonomialIdeal` is a subclass of `Ideal` — it inherits all the
ideal operations, but specific methods are overridden to use the
fast monomial-ideal path.

## Construction

- **`monomialIdeal(m1, m2, …)`** — directly from monomials.
- **`monomialIdeal I`** — coerce a general `Ideal` to a
  `MonomialIdeal`. Errors if the generators aren't all monomials.
- **`leadTerm I`** + lift — common pattern to extract the initial
  monomial ideal of a non-monomial input.

## Specialised operations

The whole point of `MonomialIdeal` is that these are dramatically
faster than for general `Ideal`:

- **`intersect(I, J)`** — pure set / exponent-vector work.
- **`I : J`** — saturation / quotient.
- **`radical I`** — strip exponents to {0, 1}.
- **`primaryDecomposition I`** — recursion on variables.
- **`minimalPrimes I` / `associatedPrimes I`** — see
  [`../e/file-monideal-minprimes.md`](../e/file-monideal-minprimes.md)
  and [`../e/file-assprime.md`](../e/file-assprime.md).
- **`borel I` / `isBorel I`** — Borel closure.
- **`Hilbert series / function`** — via Bigatti's algorithm
  ([`../e/file-hilb.md`](../e/file-hilb.md)).

Each is `O(complexity in exponent space)`, not `O(complexity in
polynomial space)`.

## Engine backing

A `MonomialIdeal` carries a `RawMonomialIdeal*` pointer
([`../e/file-monideal.md`](../e/file-monideal.md)). The engine
stores the ideal as a set of sparse-monomial exponent lists
([`../e/file-ExponentList.md`](../e/file-ExponentList.md)).

## Used by

- M2's `monomialIdeal` and friends.
- The toric-geometry, Stanley-Reisner, simplicial-complex packages.
- Initial-ideal computations inside other algorithms.
