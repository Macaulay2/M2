# `multilin.m2` — multilinear operations (`exteriorPower`, `minors`)

`multilin.m2` provides **multilinear operations** on matrices and
modules: `exteriorPower`, `symmetricPower`, `minors`, `pfaffians`,
`fittingIdeal`. It is the M2-side dispatcher for these standard
linear-algebra constructions.

Part of the [`m2/` Core layer](README.md).

## Operations

- **`exteriorPower(p, M)`** — `Λ^p M` for a module or matrix.
- **`symmetricPower(p, M)`** — `Sym^p M`.
- **`minors(p, M)`** — the ideal generated by the `p × p` minors.
- **`pfaffians(p, M)`** — `p × p` Pfaffians of a skew-symmetric
  matrix `M`.
- **`fittingIdeal(p, M)`** — the *p*-th Fitting ideal of a module.

All five operations are method dispatchers; each branches on whether
the input is a `Matrix` or a `Module`.

## How implementations choose

For `minors`, the engine has three strategies (see
[`../e/file-det.md`](../e/file-det.md)):

- `DET_BAREISS` (default for integer / polynomial input)
- `DET_COFACTOR` (default for sparse input)
- `DET_DYNAMIC` (default for small dense input)

The choice is automatic; the user can override via `Strategy => …`.

For `pfaffians`, the engine uses
[`../e/file-pfaff.md`](../e/file-pfaff.md).

## Used by

- Algebraic-geometry packages (every variety has Fitting ideals).
- M2 users computing module presentations.
- Schubert calculus (`exteriorPower`).
