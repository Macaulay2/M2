# `m2-types.{h,cpp}` (in `interface/`) — engine-side type aliases for the interpreter

`interface/m2-types.h` declares the **basic type aliases** the engine
shares with the interpreter — `M2_bool`, `M2_arrayint`, `hash_t`, plus
platform-dependent feature checks. It is the lowest-level public header
in `interface/`; every other public header includes it transitively.

Part of the [`interface/`](README.md) subdirectory.

[← interface overview](README.md) · [← engine overview](../README.md)

## Header preamble

```c
#pragma once
// IWYU pragma: private, include "engine-includes.hpp"

#ifndef _GNU_SOURCE
 #define _GNU_SOURCE
#endif

#include <stdint.h>
#define hash_t uint64_t
#include <M2/config.h>

extern char newline[];

#ifdef HAVE_UNISTD_H
 #include <unistd.h>
#endif
#ifdef HAVE_MATH_H
 #include <math.h>
#endif
#ifdef HAVE_SYS_RESOURCE_H
 #include <sys/resource.h>
#endif
```

Three sets of definitions here:

1. **`hash_t`** — the engine's hash-value type. A 64-bit unsigned integer.
   Used by every engine class with a `hash()` method.
2. **Platform feature checks** — `HAVE_UNISTD_H`, `HAVE_MATH_H`, etc.
   come from `M2/config.h` (generated by configure).
3. **`newline`** — the platform's line terminator, set up once at
   startup.

The `IWYU pragma: private` directive tells the
[Include-What-You-Use](https://include-what-you-use.org/) tool that
this header is an implementation detail — callers should include
`engine-includes.hpp` instead.

## Other declared types

The rest of the header declares:

- **`M2_bool`** — the bool type passed across the engine boundary.
  Typedefed to `int` to keep ABI-stable across C/C++ compilations.
- **`M2_arrayint`** — pointer to a length-prefixed `int` array. The
  standard return type for "list of small integers" results (degree
  vectors, Betti tables, etc.).
- **`M2_string`** — pointer to a length-prefixed string. Used for
  ring names, variable names, error messages.

All of these are GC-managed types; their layout matches the
interpreter's expectations exactly.

## Used by

Every other `interface/*.h` header pulls in `m2-types.h` (transitively
via `engine-includes.hpp`). The interpreter side uses the same types
via the bridging headers generated by `scc1`.
