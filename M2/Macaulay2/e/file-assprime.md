# `assprime.{cpp,hpp}` — `AssociatedPrimes`

`AssociatedPrimes` computes the **codimension** and the **associated primes
of minimal codimension** of a monomial ideal. It operates on a `MonomialIdeal`
([`file-monideal.md`](file-monideal.md)) and returns its results in monomial
form.

Part of the [Other computations](computations.md) area.

[← per-area: computations](computations.md) · [← engine overview](README.md)

## State

```cpp
class AssociatedPrimes {
    enum { do_codim, do_primes } state;   // which job we're doing
    int min_codim;
    int nvars;
    MonomialIdeal *mi;          // a radical monomial ideal (input)
    MonomialIdeal *ass_primes;  // associated primes of minimal codim
    // ...
};
```

The class is **state-machine-shaped**: it knows whether it is currently
computing the codimension or computing the minimal-codimension primes, and
its public methods step accordingly. This lets the user run just the
codimension calculation (cheap) and only ask for the primes (expensive)
afterwards.

## Why monomial primary decomposition is easier

For a **monomial ideal** `I ⊂ k[x_1, …, x_n]`, the associated primes are
themselves monomial primes — each is generated by a subset of the variables.
This reduces primary decomposition to a combinatorial problem on the
exponent vectors, with no need to compute Gröbner bases or operate over
infinite-precision coefficients.

The standard recursion is:

```
ass(I) =  ass(I, x_i)  ∪  { (x_i) + ass(I : x_i^∞) }    for some chosen i
```

Either the variable `x_i` is in the prime, or it isn't; recurse on both
branches and intersect / union appropriately.

## Inputs and outputs

- Input: a **radical** monomial ideal `mi`. The radical step is the
  caller's responsibility (or use `MonomialIdeal::radical()`).
- Output: `ass_primes` — a `MonomialIdeal` where **each generator** is a
  squarefree monomial encoding one prime as `(x_{i_1}, …, x_{i_k})`
  (variables appearing in the monomial).

The choice of "monomial ideal of primes" as the output type is a
representation trick: it gives a compact, set-like storage with the
engine's existing monomial-ideal machinery for free.

## Used by

- Primary decomposition of general ideals (after passing through the
  initial monomial ideal).
- Codimension queries (`codim I`) for monomial ideals.
- Dimension queries (`dim R/I`).
